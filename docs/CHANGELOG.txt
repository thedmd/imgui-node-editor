v0.9.4 (WIP):

    NEW: Editor: Add smooth zoom (#266)

    NEW: Canvas: Add IsVisible(); Begin() returns true also for a canvas out of view

    BUGFIX: Canvas: Remember index of first command buffer to not miss updating any used (#260)

    BUGFIX: Editor: Don't duplicated ImVec2/ImVec3 == != operators defined since ImGui r19002 (#268)

    BUGFIX: Examples: Use imgui_impl_opengl3_loader.h instead of gl3w (#264)

    BUGFIX: Editor: Restore node state from Config::LoadNodeSettings when node is created
        Since v0.9.1 state provided by application was ignored and overwritten
        by Config::SaveNodeSettings with default location.

    BUGFIX: Editor: Make Suspend/Resume work inside BeginNode/EndNode (#282)

    BUGFIX: Editor: Pass AddRect() and PathStroke() arguments in order used since ImGui r19276 (#339), thanks @pthom

    BUGFIX: Editor: Don't duplicate float * ImVec2 operator defined since ImGui r19268 (#335), thanks @sonoro1234

    BUGFIX: Editor: Build with Dear ImGui before 1.91.5 again (#330), thanks @LAK132
        ImGui::GetKeyIndex() was defined in ImGui's namespace, as ImGui itself does up to 1.91.4,
        and IM_TRUNC was used, which ImGui defines since 1.90.

    BUGFIX: Editor: Don't use ImDrawFlags_RoundCornersAll renamed in ImGui 1.93

    BUGFIX: Canvas: Set draw list pixel density with _SetPixelDensity() since ImGui r19292
        Zoomed canvas lost anti-aliasing with ImGui 1.93.

    BUGFIX: Editor: Set draw list pixel density with _SetPixelDensity() since ImGui r19292

    BUGFIX: Editor: Keep stroke placement of borders and grid since ImGui r19298
        With ImGui 1.93 the selection border was hidden and grid lines were blurred.

    BUGFIX: Editor: Write IMGUI_NODE_EDITOR_VERSION_NUM in decimal
        000904 was an octal literal with the digit 9, so any version check failed to compile.

    BUGFIX: Editor: Offer created item to application only once
        Rejected items were offered again on every frame, and a drag cancelled after
        the item was accepted left BeginCreate() returning true until the next drag.

    BUGFIX: Editor: Drop references to deleted objects before freeing them
        Freed nodes, pins and links were still read through the selection, the link under the mouse,
        flow animations, the DeleteNode()/DeleteLink() queue and pending new links.
        GetLinkPins() returns false for a link whose pins were deleted.

    BUGFIX: Editor: Stop flow animations when their link is deleted
        Finished animations are reused. Style::FlowMarkerDistance is at least one canvas pixel; a negative
        value drew markers without end.

    BUGFIX: Editor: Clear the current editor when DestroyEditor() destroys it
        API calls without a current editor assert instead of dereferencing null.

    BUGFIX: Editor: Don't select an object twice
        Selecting a selected node with append, then deselecting it, left it drawn as selected.

    BUGFIX: Editor: Return no node background draw list between frames

    BUGFIX: Editor: Keep node sizes and the view while the host window skips items
        A collapsed host, a hidden dock tab or a child window scrolled out of view overwrote group sizes
        and squeezed the view, and both were saved.

    BUGFIX: Canvas: Enter local space and reserve layout space also when the canvas is clipped
        Content of a canvas out of view was drawn untransformed, and content below it moved up.

    BUGFIX: Editor: Don't draw or hit-test the graph over the host window while the canvas is out of view
        Interactions and saving wait until the canvas is visible again.

    BUGFIX: Editor: Count nested Suspend()/Resume() pairs
        A second Suspend() brought back the editor's own draw list splitter in screen space.

    BUGFIX: Editor: Accept or reject only the deletion candidate a query returned
        A second AcceptDeletedItem() deleted the next, unreported candidate, and RejectDeletedItem() after
        the query loop read out of bounds. Both assert now without a current candidate.

    BUGFIX: Editor: Assert on a pin submitted twice in one frame instead of hanging in ed::End()

    BUGFIX: Editor: Use the node padding BeginNode() saw in EndNode()
        Pushing StyleVar_NodePadding around only one of the two calls broke ImGui's group stack.

    BUGFIX: Editor: Return no node draw list or group hint while a node is built
        GetNodeBackgroundDrawList() and BeginGroupHint() inside BeginNode()/EndNode() corrupted memory;
        they assert and return nothing now. The background draw list is available after EndNode().

    BUGFIX: Editor: Validate the style stacks
        An extra PopStyleColor()/PopStyleVar() or a PushStyleVar() of the wrong type crashed release builds;
        they assert and do nothing now. End() asserts when pushes and pops don't balance within the frame.

    BUGFIX: Editor: Collect group content once, and center a group with all of it
        A group fitting inside its own group area overflowed the stack, nested content was moved twice,
        and CenterNodeOnScreen() left content submitted after the group in place.

    BUGFIX: Editor: Write and read settings numbers independently of the locale
        Under a locale with a decimal comma positions were saved wrong, and the first ed::Begin()
        switched LC_NUMERIC to "C" for good.

    BUGFIX: Editor: Write non-finite numbers in settings as null
        A single NaN or infinity, such as a zoom, made the saved settings unreadable.

    BUGFIX: Editor: Make crude_json lookups safe on unexpected documents
        Missing keys, wrong types and out-of-range indices crashed or terminated the process.

    BUGFIX: Editor: Validate settings when loading them
        Pin or link entries among the nodes asserted. A zoom of zero or less, or one outside the zoom
        levels, broke the view or hung the first frame; it is clamped to the zoom levels now.

    BUGFIX: Editor: Bound the grid drawing loop
        A view wider than 2^29 canvas units, such as navigating to content 10^9 units across, hung the frame.
        Grid lines less than 2 pixels apart, or fully transparent, are not drawn.

    BUGFIX: Editor: Change settings once a navigation settles, not on each of its frames
        One wheel notch changed them 10 times, and NavigateToContent() 21 times.

    BUGFIX: Editor: Don't change settings when a fractional position is set again
        SetNodePosition() and SetGroupSize() called with the same fractional value changed them on every call.

    BUGFIX: Editor: Pick the group edge to resize where the drag started
        A fast first move did nothing or moved the group, and a resize with DragButtonIndex other than 0
        didn't follow the mouse.

    BUGFIX: Editor: Keep a dragged node under the mouse when the view zooms
        Zooming during a drag or a group resize moved the node or the edge away from the mouse.

    BUGFIX: Editor: Stop a navigation animation when a pan starts
        A pan right after a wheel notch drifted, then jumped, while the zoom animation went on.

    BUGFIX: Editor: Zoom around the point under the mouse while a zoom animation plays
        Quick wheel notches zoomed around a point away from the mouse.

    BUGFIX: Editor: Give nodes and pins separate hit-test IDs
        Dragging node 1 above pin 1 of another node started a link from the pin.

    BUGFIX: Editor: Don't report empty nodes and pins as clicked
        An item-less pin made the node above it start a link instead of moving, and with ImGui before 1.91
        an empty node was selected on every frame.

    BUGFIX: Editor: Report background double-clicks with mouse button indices
        GetBackgroundDoubleClickButtonIndex() returned 1, 2 and 4, and a right double-click went unnoticed.

    BUGFIX: Editor: List the shortcut context in GetActionContextNodes() and GetActionContextLinks()
        They listed the selection, without a hovered node, the contents of selected groups or the links
        between the nodes, so they didn't add up to GetActionContextSize().

    BUGFIX: Editor: Ignore context menu clicks outside the editor
        A right-click released outside the editor made an empty context menu current, which blocked other
        input, such as Ctrl+C, in that frame.
